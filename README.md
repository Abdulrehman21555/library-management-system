# Library Management System

## Project Overview

The Library Management System is a full-stack system designed to manage library operations.

The system consists of two separate panels:

- Admin Panel
- User Panel

Both panels communicate with a shared backend through APIs and use a common database.

## Admin Panel

The Admin Panel is used by administrators to:

- Manage books
- Manage users
- Manage borrowing records
- Check book availability

## User Panel

The User Panel allows users to:

- Browse books
- Search for books
- Check book availability
- Request books

## Backend

The backend handles the main business logic of the system and processes requests received through the API.

## API

The API provides communication between the Admin Panel, User Panel, and Backend.

## Database

The database stores:

- Book information
- User information
- Borrowing records
- Book requests
